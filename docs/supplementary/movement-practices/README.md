# Comprehensive DAG of World Movement Practices & Cultures

This package maps deliberately cultivated human movement in the broadest practical sense: dance, martial arts, sport, exercise, somatics, ritual, theatre, circus, locomotion, outdoor skills, aquatic practice, work, subsistence, rehabilitation, play, animal-partnered movement, military/service movement, education, and digitally mediated movement.

## Files
- `movement_practices_dag.svg` — full visual graph.
- `movement_practices_overview.svg` — readable top-level map.
- `movement_practices_dag.dot` — editable Graphviz source.
- `movement_practices_graph.json` — machine-readable nodes and edges.
- `movement_practices_index.csv` — searchable index with parent relations.

## Scale

## Ontology
The graph is a DAG rather than a tree. A practice may have several parents because movement cultures overlap. Capoeira, for example, is simultaneously martial, danced, ritualized, playful, acrobatic, and culturally specific.

Solid edges indicate primary containment. Dashed orange edges indicate cross-domain membership. Dotted purple edges indicate cross-cutting dimensions.

## Honest scope boundary
No finite list can literally include every local name, lineage, school, extinct practice, household custom, occupational technique, disability adaptation, children's game, or undocumented Indigenous practice. This version is therefore a comprehensive *world ontology and large reference index*, not a claim of final census completeness. Its editable formats are designed for continued expansion.
